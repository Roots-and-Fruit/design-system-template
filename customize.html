Agent path (preferred)

Step Do this Done when
1 Open brand.json. Set name, tagline, description, colors, fonts, rounded. Set placeholder to false. Values match the real brand
2 Run npm run customize (or node scripts/apply-brand.mjs). No npm install required. Script exits 0; tokens, fonts import, DESIGN.md front matter, sidebar name, and embed are updated
3 Rewrite DESIGN.md prose: Overview, Colors pairing notes if needed, Typography voice, Do’s and Don’ts. Keep token names. No “Example Brand” in the prose
4 Run npm run customize again (or npm run sync:design-md) so design-md.html carries the new prose. DESIGN.md page shows the new copy
5 Replace assets/mark.svg and add logos under assets/logos/. Update the inlined mark in each page’s sidebar if you want the chrome to match. Placeholder geometry is gone
6 Optional: npx -p "@google/design.md" designmd lint DESIGN.md Errors at zero
